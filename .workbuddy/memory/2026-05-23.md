## dose_app.py 双峰剂量计算逻辑修正

- **问题**：旧逻辑用 `stage_integral` 归一化后用全局 frac 拆分，等价于简单比例分配，未体现每级粒径对两峰的归属差异
- **新逻辑（逐级 pdf 权重分配）**：
  - 对每级中值粒径 `d_i`，计算 `pdf1_i = frac1 * lognormal_pdf(d_i, AMAD1, GSD1)`，`pdf2_i = frac2 * lognormal_pdf(d_i, AMAD2, GSD2)`
  - 权重：`w1_i = pdf1_i / (pdf1_i + pdf2_i)`，`w2_i = 1 - w1_i`
  - 两峰活度汇总：`C1 = Σ w1_i * C_i`，`C2 = Σ w2_i * C_i`
  - 总剂量：`D = e(AMAD1)*C1*BR*T + e(AMAD2)*C2*BR*T`
- 输出：`dist/剂量计算系统.exe`（143.7 MB，含全部核素数据文件）
