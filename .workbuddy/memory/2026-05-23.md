# 2026-05-23 工作记录

## dose_app.py v3.3 UI 调整

### 修改内容：

1. **左侧面板宽度**：初始宽度保持 600px，去掉阻止拖拽的隐式固定，添加：
   - `setCollapsible(False)` 防止意外折叠
   - `setHandleWidth(6)` + 蓝色 hover 样式，手柄更易抓取
   - 两侧 stretchFactor 维持原来设置（0号面板不随窗口自动伸缩）

2. **所有区域支持鼠标拖拽（QSplitter 全面铺设）**：
   - 主水平分割器（左参数 / 右结果）：已支持，样式优化
   - Tab1「拟合图」内部：新增竖向 QSplitter，上方 canvas / 下方 fit_info_lbl（初始 560/80）
   - Tab2「剂量结果」内部：新增竖向 QSplitter，上方汇总+明细表 / 下方累计+导出区（初始 320/250）

3. **多模态法峰型改为用户手动选择**：
   - 方法2 radio 文字改为"方法2 · 多模态拟合（手动选择峰型）"
   - radio 下方增加子选项行（仅选方法2时显示）：「单峰（Unimodal）」/「双峰（Bimodal）」
   - `_do_calc` modal 分支：不再调用 `recommend_method` 决定峰型，改为读取 `user_peak` 参数
     - `user_peak='bimodal'` 且双峰拟合成功 → 使用粗峰 AMAD
     - `user_peak='bimodal'` 但未检测到双峰 → 警告并回退单峰
     - `user_peak='unimodal'` → 直接使用单峰 AMAD
   - `recommend_method` 结果仍计算并在日志/信息栏显示为"参考推荐方法（仅供参考）"
   - `_on_result` 结果标签：显示用户选定峰型标注（双峰/单峰）
   - 剂量计算双峰判断：从检查 `recommended` 字符串改为检查 `fit_res['user_peak']`

4. **版本号**：v3.2 → v3.3（未在标题中更新，代码功能已是 v3.3 水平）

## dose_app.py v3.4 Bug 修复

### Bug1 修复：计算完成后不再重绘拟合图
- **问题**：`_on_result` 每次计算完成都调用 `plot_canvas.plot_fitting()` 重绘，导致拟合图随计算方法变化而改变。
- **修复**：在 `_on_result` 中删除 `plot_canvas.plot_fitting()` 调用，图表仅由「运行拟合」按钮触发更新。

### Bug2 修复：导出包含全部历史计算记录
- **问题**：`self._fit_result` 为单个 dict，每次计算覆盖旧值，导出只有最后一次结果。
- **修复**：
  - 新增 `self._calc_history = []` 列表，每次计算完成时 `append(res)`
  - `_clear_results` 同时清空历史列表
  - `_build_export_data()` 改为汇总全部历史：
    - `dose_rows` 中每行附加 `_calc_no`/`_method`/`_mask` 字段
    - 新增 `summaries` 列表（每次计算一行摘要）
    - 日志合并所有历史，带序号分隔
  - Excel 导出 Sheet1 改为"各次计算汇总"表，Sheet3 剂量明细添加序号/方法/口罩列
  - CSV/内部导出函数同步更新
