# 2026-05-21 工作记录

## 空气采样法剂量计算系统 v3.0（桌面版）完成

### 新建/修改文件
- `dose_app.py` — 全新 PyQt5 桌面 GUI 应用，替代原 Streamlit 版本
- `sampling_data.csv` — 扩充示例数据，新增 nuclides/compounds/activity_fractions/nuclide_abundances 四列

### 主要功能
1. **数据输入**：手动输入9级浓度 或 读取 CSV/Excel（自动解析车间/采样ID/化合物配置）
2. **四种计算方法**：
   - 方法1：国标单AMAD（固定5μm）
   - 方法2：多模态拟合（单峰/双峰自动判断+推荐）
   - 方法3：Probit 直线拟合法
   - 方法4：逐级独立法（每级中值粒径查表累加）
3. **剂量系数 e 计算逻辑**：
   - 双峰模式：通过stage_integral计算每级对各峰的归一化贡献比例，加权得到等效浓度，再乘以各峰的e值
   - 逐级法：直接用midpoints[i]对每级查表，按"级-核素-化合物"三维矩阵累加
4. **口罩防护**：逐级按midpoints粒径计算防护因子，口罩类型支持7种国标型号
5. **参数**：BR（呼吸速率）、T（工作时长）、化合物-核素-丰度三维配置
6. **结果展示**：拟合图(3子图)、剂量明细表、累计列表、完整计算日志

### 运行方式
```
python dose_app.py
```
需依赖：PyQt5, matplotlib, scipy, scikit-learn, pandas, numpy, pyarrow

## v3.1 Bug修复 & 数据调整（2026-05-21 下午二轮）

**问题**：从CSV读取采样数据后弹出"至少保留一个化合物行"提示框。

**根因**：`_fill_compounds_from_row()` 中调用 `_remove_compound_row()` 逐一删除现有行，删到最后1个时触发了用户保护逻辑弹窗。

**修复**：改为直接操作布局和列表（`removeWidget + deleteLater + list.clear()`），绕过用户保护检查，仅在程序内部自动填充时使用。

**丰度调整**：`sampling_data.csv` 中将 `U_235:0.007` 改为 `0.15`，`U_239:0.007` 改为 `0.10`，使界面丰度显示更合理（不要求与实际同位素丰度一致）。

## v4.1 交互修复 & 数学排版（2026-05-21 下午四轮）

**问题1**：自动拟合太快，选完采样ID立即绘图，用户希望手动控制流程。

- 用户流程：选CSV → 选车间 → 选采样ID → 数据自动填入浓度表 → 点击"运行拟合" → 图表更新

**问题2**：matplotlib 图表中上下标（D84.1, D15.9, R², μm, m³）无法正常显示。

**修复**：
- 添加 `matplotlib.rcParams['mathtext.fontset'] = 'stix'`
- 图表标签中的数学符号改用 LaTeX 数学模式：
  - `μm` → `$\mu m$`
  - `D84.1` → `$D_{84.1}$`
  - `D15.9` → `$D_{15.9}$`
  - `R²` → `$R^2$`
  - `AMAD(D50)` → `$AMAD(D_{50})$`

**问题3**（v4.1 补充）：右下角参数摘要仍显示方框。

**根因**：该区域使用 `ax.text(family='monospace')`，等宽字体（Consolas/Courier）缺少希腊字母 μ 和上标 ² 字形。

**修复**：
- 移除 `family='monospace'`，使用默认 sans-serif 字体（SimHei/微软雅黑）
- 特殊符号统一改为 LaTeX 数学模式：`\u03bcm` → `$\\mu$m`，`\u00b2` → `$^2$`，AMAD/GSD → `$AMAD$`/`$GSD$`

## Bug修复：核素数据查找失败（2026-05-21 下午五轮）

**现象**：计算时所有核素报 `[警告] 找不到核素 U_238/U_235 数据，跳过`，总剂量 = 0。

**根因**：CSV 中核素名用下划线格式 `U_238`，但 parquet 文件 radionuclide 列用连字符格式 `U-238`。`_nuclide_files` 以 parquet 原生值 `U-238` 为 key，`get_nuclide_df('U_238')` 查找不到。

**修复**（dose_app.py 两处）：
1. 加载时归一化（第110行）：`str(df['radionuclide'].iloc[0]).replace('_', '-')`
2. 新增 `_normalize_nuclide()` 辅助函数，`get_nuclide_df()` 入口统一归一化输入
