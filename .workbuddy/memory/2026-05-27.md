## Bug 修复 #3（2026-05-27 11:36）——DEFAULT_STAGES 粒径边界错误导致拟合图像不同

### Bug 5 (CRITICAL): DEFAULT_STAGES 粒径边界整体偏移一位
- **根因**: v4.0 重构时 DEFAULT_STAGES 的 low/high 值整体比 xf_core.py 下移了一位
  - 错误: A级 low=14.8 high=21.3（实际是B级范围）、Filter级 low=0.04 high=0.1（编造值）
  - 正确 (xf_core原生): A级 low=21.3 high=50.0、Filter级 low=0.1 high=0.5
- **影响**: fit_unimodal/fit_bimodal 用 stages_low/high 做 CDF 积分，边界错误 → AMAD/GSD 完全不同
  - PowderPrep/Sampling4 修复前: AMAD=3.625, 修复后: AMAD=5.820
- **修复**: DEFAULT_STAGES 9级 low/high 对齐 xf_core.stages_low / stages_high

### Bug 6: _patch_xf_stages cut_diameters 默认值错误
- **根因**: `cut = high[:-1]` → 应为 `low[:-1]`（即相邻级之间的边界粒径）
- **影响**: fit_linear_probit 用 cut_diameters 做 x 轴 → probit D50 从 9.562 变回 5.369
- Bug 5 掩盖了 Bug 6（错误边界 + 错误 cut_diameters 意外互相抵消）
- **修复**: `high[:-1]` → `low[:-1]`

### 修复后验证 (PowderPrep/Sampling4, 无防护)

## Bug 修复 #4（2026-05-27 15:11）——_rm_card crash + 拟合图被覆盖 + 化合物下拉 + 分辨率

### Bug 7: _rm_card 崩溃（手动输入化合物时报错）
- **根因 1**: 变量名 `si` 遮蔽——`_rm_card` 中 `si` 先被赋为 `selectedItems()` 返回的列表，后被赋为 `si[0].row()`，但 lambda 回调 `db.clicked.connect(lambda ch, c=card: self._rm_card(c))` 传入 card 对象后，内部 `si` 来自表格选中状态，可能不一致
- **根因 2**: `return QMessageBox.information(...)` 返回值非 None
- **修复**: `_rm_card(card, si)` — si 由 lambda 闭包捕获（`lambda ch, c=card, si=idx: self._rm_card(c, si)`），避免依赖运行时表格选中状态

### Bug 8: _on_result 自动重绘拟合图覆盖 _on_fit 的图像
- **根因**: `_on_result` 第 1050-1052 行对 modal/probit 方法自动调用 `_redraw_fit_plot`
  - std/stage 方法的 `_do_calc` 不产生真实拟合参数，默认值覆盖了 _on_fit 的完整拟合结果
- **修复**: 移除 `_redraw_fit_plot` 调用，仅更新 `self.fil` 标签文字；拟合图像完全由「运行拟合」按钮控制
